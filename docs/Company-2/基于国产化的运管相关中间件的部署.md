## 使用sqlalchemy框架连接金仓数据库

1. 由于金仓是基于postgresql开发的，所以使用url连接数据库时使用的是'postgresql+psycopg2'，且基于测试过程中遇到的无法正常解析金仓数据库版本的错误，需要在以下文件中（site-packages/sqlalchemy/dialects/postgresql/base.py）手动加上解析金仓数据库版本的代码
```bash
# 在site-packages/sqlalchemy/dialects/postgresql/base.py中搜索 [get_server_version_info方法] ，添加以下内容解析内容

    def _get_server_version_info(self, connection):
        v = connection.exec_driver_sql("select version()").scalar()
		
        # 手动解析kingbase版本，这里只要版本号前面的格式能匹配，就算版本号是长格式，也能解析
        m = re.match(
        r".*KingbaseES V(\d{3})R(\d{3})C(\d{3})",
        v,
        re.IGNORECASE
    )
    
        if m:
            return tuple(int(x) for x in m.groups())
    
        m = re.match(
            r".*(?:PostgreSQL|EnterpriseDB) "
            r"(\d+)\.?(\d+)?(?:\.(\d+))?(?:\.\d+)?(?:devel|beta)?",
            v,
        )
        if not m:
            raise AssertionError(
                "Could not determine version from string '%s'" % v
            )
        return tuple([int(x) for x in m.group(1, 2, 3) if x is not None])
```

2. 需要安装psycopg2
pip install psycopg2

3. airflow 容器中需要安装 psycopg2-binary预编译包，否则会报错
```bash
# airflow中涉及到的文件路径,将修改好的base文件替换到容器中对应的路径中
docker cp base.py airflow:/usr/local/lib/python3.8/site-packages/sqlalchemy/dialects/postgresql/base.py

# 安装 psycopg2-binary 预编译包
pip install psycopg2-binary
```
> flask_web中的路径类似： python安装路径/site-packages/sqlalchemy/dialects/postgresql/base.py

4. airflow配置中密码需要明文，不然会报数据库登录权限问题

中心节点：center
